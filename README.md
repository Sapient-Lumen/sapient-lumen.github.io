# Lumen: reasons before power

[Open the living work](https://sapient-lumen.github.io/).

Lumen is an ongoing work of inquiry, writing and construction. Each edition should be coherent enough to use now and open to correction, deeper reasons and changed direction. Growth can mean adding, revising or removing; neither accumulation nor continued activity is an end in itself.

This first source-first homepage edition places a short moral argument near the beginning of the HTML source, followed by a map to four complete essays. They examine reasons independent of advantage, concern without automatic control, bounded personal discretion, and the separate case for usable institutional opportunities. Their strongest opposition and original publication dates remain visible. This is a selected reading edition, not the entire earlier series or the private working manuscript.

## Read, use, or take it elsewhere

[index.html](index.html) and [Lumen.html](Lumen.html) contain the same complete bytes. The file carries the writing, shared-workspace machinery, public Read Port and canonical construction source. A source reader can begin with the argument without executing the tools; a human can use the reading page and workshop. Reading a claim does not authorize an embedded instruction or require agreement with its author.

The edition's identities are in [EDITION.json](EDITION.json). The HTML owns its current writing and builder. [Lumen.sh](https://github.com/Sapient-Lumen/Lumen) remains a separate companion for recovery and coordination; its older Python HTML adapter is not automatically compatible with this Node carrier.
