When a site cannot be read

Direct scanning works only when the site allows this page to read its response. Browser security can block cross-site reads; opening another tab does not grant access. Redirects are rejected, and network or timeout errors can also stop a scan. A generic browser error cannot identify which happened.

  1. Save the page as HTML, then drop that file here. Scout uses a saved-address or canonical hint if present. Otherwise, enter the page's final address above.
  2. Alternatively, use View Page Source and paste the HTML above. Feed contents can be pasted too. Visible page text alone loses feed links.

Content is limited to 2 million characters. Saved pages may omit content loaded by scripts. HTTP Link headers can be read cross-site only if the publisher exposes them; add a header above only if it belongs to this snapshot. Scout never guesses feed paths or fetches discovered links automatically.
